# HUSH 3D

Prosty prototyp gry typu 3D stealth survival w Godot 4.

## Sterowanie
- W / A / S / D — ruch
- LPM — strzał
- R — restart po przegranej

## Mechanika
- Gracz porusza się po pustym polu.
- Wrogowie pojawiają się w kolejnych falach i gonią gracza.
- Strzał jest szybki, ale amunicja jest ograniczona.
- Po utracie wszystkich punktów zdrowia gra kończy się.

## Uruchomienie
1. Otwórz folder projektu w Godot 4.
2. Uruchom `scenes/Main.tscn`.
3. Gra działa bez dodatkowych assetów.
